# Baritone Weekly Practice Log

A structured week of practice for rebuilding tone and smooth register transitions. Designed for comeback players practicing at home between band sub gigs.

**Daily target:** 20–40 minutes. Stop while tone is still decent — fatigue causes splats and stiff range changes.

**Session order (every day):**

| Block | Time | Focus |
|-------|------|-------|
| Warm-up | 5–8 min | Long tones, mouthpiece buzzing |
| Attacks | 5 min | Soft, even note starts |
| Lip slurs | 8–10 min | Register transitions (main priority) |
| Melody | 5–8 min | Slow legato tunes or études |
| Cool-down | 2 min | Easy long tones |

---

## How to use this log

1. Copy the **Week of: ________** section below into a new heading each Sunday (or start fresh in a new file).
2. Check off blocks you completed; jot brief notes — especially on splatty attacks or rough register jumps.
3. Pick **one focus per week** from the rotation table; don't try to fix everything at once.
4. Before a band sub gig, spend the prior 2–3 days on **warm-up + melody** (band parts), not heavy range work.

### Weekly focus rotation

| Week | Primary focus | Secondary |
|------|---------------|-----------|
| A | Even attacks (no splat) | — |
| B | Lip slurs / register smoothness | — |
| C | Legato and phrasing | — |
| D | Band repertoire / sight-reading | Light long tones |

Repeat the cycle. Mark which letter you're on in the week header.

### Reference exercises

**Long tones (warm-up):** Middle register, e.g. B♭–F–B♭ (concert pitch). Start with "HOO" — air before tongue. 8–12 seconds per note, pianissimo to mezzo-piano.

**Attacks:** Single pitch, soft "TOO" tonguing. 4–6 attacks, rest, repeat. If it splats, less tongue and more air.

**Lip slurs (no tongue):** Start with open partials — B♭–F–B♭, F–B♭–D, B♭–D–F. Slow and soft. Add wider intervals only when clean.

**Melody:** Simple tunes, hymn tunes, or band parts at **half tempo**. One musical goal per session (e.g. connected notes, steady air).

## Before a band sub gig

Use this checklist 1–2 days before rehearsal:

- [ ] 15–20 min session: long tones + easy melody only (no heavy slurs)
- [ ] Review fingerings / clef for any tricky passages in the folder
- [ ] Mouthpiece buzzing: 2 min on first few notes of hard passages
- [ ] Pack: horn, mouthpiece, music, pencil, water

**Day-of warm-up at the hall (10 min if possible):**

1. Buzzing — 2 min
2. Long tones — 3 min
3. Lip slur one partial (B♭–F–B♭) — 2 min
4. Run problem licks from the set at half tempo — 3 min
